# ShotMill AI Agent 调用能力方案

日期：2026-09-22。状态：设计草案，尚未实现。用户要求先计划。

## 目标与边界

让支持 HTTP、命令行或 MCP 的 AI Agent 都能可靠地操作 ShotMill：发现能力、选择项目与素材、创建任务、增强提示词、提交生成、跟踪结果和管理队列。Agent 不必操作网页，不需要理解数据库、ComfyUI 节点或读取含密钥的设置文件。

自然语言拆剧本、导演判断仍由调用方负责。ShotMill 负责数据校验、媒体真实性、执行快照与后台调度。不在这项能力中实现自动循环审查。

**用户最新决策：提示词增强和提示词审核都是可选步骤，不得作为单任务或批量生成的强制前置条件。** 用户可以直接使用当前选择的用户提示词或 AI 提示词生成。该决策覆盖旧版“必须先增强、人工审核后才可批量生成”的产品规则。Agent 接入仍是计划；现有应用的强制审核门禁已按这项独立需求移除，沿用有效提示词与执行校验。

## 建议架构

以现有 Application Service 为唯一业务实现，提供稳定的版本化 HTTP 契约与精简 Agent 读模型；在其上提供 `shotmill` CLI，随后增加薄 MCP 适配层。三种入口共享同一验证、权限、幂等和错误语义，不各写一套生产流程。

优先交付 HTTP + CLI + 调用说明。HTTP 可被任意语言调用；CLI 便于具备终端的 Agent 使用；MCP 服务于支持工具发现的客户端，但不作为唯一入口。无需引入新的队列系统或数据库。

## 当前已有与缺口

已有：项目列表/创建/配置、资产导入/分类、任务创建/修改/排序、提示词增强与批量审核、视频提交与结果、全局运行中心、队列挂起/恢复/移除、事件通知。入口在 `backend/shotmill/api/`，继续复用其服务层。

缺口：正式项目/任务删除、带预检的成组创建、稳定幂等键、完整媒体传递回执、精简能力发现、统一操作回执、面向 Agent 的调用文档与权限控制。此次旧版删除需要直接维护数据库和文件，这不能成为对外调用范例，首期必须补正式服务。

## 面向 Agent 的操作集

下列为拟议逻辑工具名，不代表现有端点已经支持。

| 能力 | 拟议操作 | 关键返回内容 |
|---|---|---|
| 发现 | `capabilities.get`、`profiles.list` | 服务版本、可用操作、可用档位、媒体限制、时长与分辨率能力 |
| 项目 | `projects.list/get/create/update` | 稳定 ID、摘要、修订号 |
| 素材 | `assets.list/import` | 稳定 ID、分类、媒体尺寸、可访问预览；按分类与名称检索 |
| 任务 | `tasks.list/get/create_many/update/reorder` | 完整创建回执、稳定 ID 与调用方临时 ID 对照 |
| 检查 | `tasks.validate` | 缺失引用、档位问题、时长限制、媒体是否真正传入、审核是否有效 |
| 增强 | `prompts.enhance` | 单项或批次 ID；后端真实排队，默认待检查 |
| 审核 | `prompts.review` | 当前 source、revision、内容 hash、审核结果 |
| 生成 | `videos.submit` | 已接受与逐项跳过原因，不将跳过伪装成成功 |
| 运行 | `runs.get/list/watch/control` | 状态、进度、耗时、错误、挂起/恢复/排序/取消结果 |
| 成果 | `results.list/get` | 视频/缩略图访问地址、所属任务、真实时长、历史版本 |
| 删除 | `projects.delete_preview/delete`、`tasks.delete_preview/delete` | 精确影响范围、删除回执、文件清理结果 |

工具描述应带中文用途和最小示例，字段名保持稳定。禁止把 API Key、完整全局设置或绝对内部媒体路径放入普通响应。

## 标准工作流

1. 读取能力及现有项目，使用稳定 ID，不能只按同名项目猜测。
2. 确认档位与素材，上传缺少的文件；只把任务确实使用的素材绑定进去。
3. 提交任务草案预检。每项包含 `clientTaskId`、剧情、提示词、秒数、档位 ID、素材引用；同一成组请求的上下文引用允许使用临时 ID，落库后映射成稳定 ID。
4. 一次创建一组任务。默认整组校验通过后事务提交，失败不留下半套项目；显式选择部分成功时，逐项报告结果。
5. 增强可跳过。用户要求增强时才提交持久化增强批次；Agent 获取实际输出和媒体回执，不能仅凭“增强成功”当成质量合格。不增强时直接使用当前用户提示词。
6. 审核可跳过。选择审核时，记录实际生效 source、revision、hash 与操作者；内容变化使原审核记录失效，但不因此禁止生成。不得把未经审核标成已审核。
7. 用户授权生成后即可提交单任务或视频批次，以当前选定提示词创建执行快照。未增强、未审核或审核记录过期都不是阻断原因；不需要 `force=true` 或额外确认弹窗。只拦截空的有效提示词、素材缺失、无效工作流、能力不支持、重复活动任务等真正无法执行的问题。镜头质量、对白节奏、未审核等提示作为非阻断 warnings 返回，允许用户承担质量风险。
8. 使用事件或带游标的等待查询跟踪，支持断线恢复。生成状态与质量评价分开；“完成”只表示产物已生成。

## 可靠性要求

- **幂等**：创建、增强、生成、删除均支持 `requestId`。同键同内容返回原回执；同键不同内容返回冲突。超时后先查询原请求，不重建重复任务。
- **并发编辑**：修改携带任务修订号。冲突返回当前修订，不能静默覆盖用户刚改的内容。
- **异步**：耗时操作立即返回批次/运行 ID。状态含终态、失败原因、是否可重试；调用方停止等待不等于任务取消。
- **队列**：提示词和视频维持独立队列。挂起只影响未开始项；移除待执行项取消排队，移除完成记录只隐藏历史入口；运行中取消是独立显式操作，能力不支持时明确拒绝。
- **媒体完整性**：报告已绑定、已解析、实际发送的引用 ID。出现数量上限不能静默截断；提交前报明不支持的引用。当前本地适配器三图限制是待解决依赖，不用“支持多图”掩盖。
- **能力来源**：限制来自 Profile/Provider Capability，不能在通用 Agent 层写死 H3、15秒、Qwen 或 ComfyUI。明确区分执行错误 errors 与质量建议 warnings，后者不能变成隐形门禁。
- **错误**：统一 `code/message/details/retryable/requestId`，区分校验、授权、修订冲突、排队、Provider 和文件错误。CLI 返回非零退出码，标准输出只放结构化结果，进度写标准错误。

## 删除与重建

删除预检返回项目 ID、任务/记录/文件数量、是否有运行中任务、其他项目是否引用相关资产。执行绑定预检摘要和修订号，防止预检后内容变动导致误删。

已有用户明确删除授权时，Agent 可依次完成预检与执行，无需让用户重复确认。彻底删除必须清理记录、项目专属视频、缩略图、缓存以及可确认归属的 Provider 副本；共享原始素材与其他项目结果不得删除。不以隐藏代替彻底删除。

数据库删除与外部文件删除不是同一个事务：持久化清理清单及进度，失败可重试；只有两者都完成才返回 `deleted`，否则返回 `cleanup_pending`。保留最小操作回执，不把被要求删除的完整内容复制成隐藏备份。

“重建任务”分为：校验新计划 → 创建新项目并校验完整性 → 按授权清理旧项目。新建失败时不先删除旧版。用户明确不保留旧版时成功后必须完成清理，不能留下两个难以区分的同名版本。

## 访问与安全

默认仅本机可用，Agent 使用独立令牌。权限按读取、编辑、提交运行、删除、管理设置区分，令牌可限制项目范围并撤销。远程开放需单独配置认证与加密传输，不能直接把本地管理接口裸露到局域网或公网。

素材导入默认上传文件；读取本地路径需要受限导入目录，不能借导入接口任意读取系统文件。素材描述、脚本和模型输出均是数据，不能成为 Agent 执行系统命令或扩大权限的指令。

## 交付顺序

**第一期：最小生产闭环**

- 梳理并固定现有 API 契约、能力发现和统一错误。
- 完成成组创建、正式删除/清理、请求幂等和修订冲突处理。
- 补全真实媒体传递预检，不能重复发生漏传遗迹参考。
- 提供 CLI 的 JSON 输入/输出、查询与等待命令。
- 提供 `AGENT_QUICKSTART.md`、参数 schema、两条正式示例：“创建→直接生成→结果”和“创建→可选增强/审核→生成→结果”；提交生成和删除遵循用户授权，不重复索要已有授权。
- 调整现有批量生成资格检查，移除强制增强/审核门禁，同时保留有效提示词快照、执行校验和重复活动任务保护；单任务、批量、UI 和 Agent 的语义一致。

**第二期：MCP 适配与接入体验**

- MCP 工具映射到同一契约，不直接访问数据库和 Provider。
- 工具清单按能力分组，简短描述，避免一次返回整项目大数据。
- 配置示例、连接诊断、令牌管理与审计查询。

自动提示词循环审查仍另立需求，不混入这两期。

## 验收

用无网页操作的独立客户端完成小型测试项目全流程。重点覆盖用户提示词未增强可直接生成、未审核与审核过期可生成、质量警告不阻断、真实执行错误阻断、重复请求不重复生成、进程重启恢复、部分失败、审核 hash 失效但不伪造确认、未授权删除拒绝、共享素材保护、外部清理失败重试、媒体漏传拒绝。HTTP、CLI、MCP 的结果必须一致，并共享 Application Service 的执行校验。

先在 Mock Provider 上跑完整契约；真实 Provider 使用少量明确授权的样例验证，不直接以整部影片充当接口测试。
