## 标准依据

- [WCAG 2.2](https://www.w3.org/TR/WCAG22/) 的 A / AA 相关条款作为可访问性目标，必须分别核验，不能用少量自动测试宣称全部达标。
- [文字对比度](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)：普通文字至少 4.5:1，大号文字至少 3:1；遵循规范中的适用条件和例外。半透明表面按实际合成后的背景核验，两种主题分别检查。
- [点击目标](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)：通常至少 24×24 CSS px，符合规范的间距等例外另行记录。本产品优先使用更舒适的 32px 及以上独立按钮，不靠缩小文字换取密度。
- [WAI-ARIA 弹窗交互模式](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)：打开时焦点进入弹窗，Tab 在有效弹窗范围内循环，Esc 关闭当前浮层，关闭后回到合理入口。APG 是交互实践指南，不等同于全部 WCAG 条款。
- [Fluent 设计原则](https://fluent2.microsoft.design/design-principles) 作为一致性、层级和操作反馈的参考；不照搬其业务布局或覆盖用户选定的风格。

## 产品验收要求

| 范围 | 通过条件 |
| --- | --- |
| 导航与发现 | 单项与批量主要操作有可见入口；不能只能靠右键或猜快捷键发现。列表、卡片切换保留选中项和数据。 |
| 编辑可靠性 | 保存有忙碌反馈、防重复提交；失败保留内容并允许重试；占位说明不能成为业务数据。 |
| 错误恢复 | 用户看得到失败原因、影响范围和下一步。持久错误不能只写日志或短暂通知。提交前校验与实际执行使用一致的条件。 |
| 长任务 | 区分提交、排队、运行、完成和失败；批量显示完成数与失败数；允许离开当前弹窗继续工作，不把关闭面板误当成取消队列。 |
| 审核正确性 | 资产标记、提示词来源和版本准确；增强进行中不允许确认旧结果；修改有效内容使原审核失效。 |
| 上下文 | 上一任务摘要是明确选择，不默认发送；图像、视频、音频引用保持稳定对应，不根据项目库顺序猜角色。 |
| 键盘与语义 | 全流程可键盘操作；焦点可见；图标按钮有可访问名称；禁用状态、错误和选中状态不只依赖颜色。 |
| 布局与主题 | 常见桌面、小窗口和移动监看检查溢出与遮挡；弹窗外框稳定；仅长列表、长编辑内容等业务区域滚动。 |
| 动效 | 打开、关闭、折叠、切换有一致过渡；尊重 reduced-motion；动画不拖延输入、不改变点击目标位置或重复提交。 |
| 真实闭环 | 实际创建项目、编辑资产和任务、批量增强、人工判断审核、单项及批量生成、查看结果；不以 Mock 成功替代真实生成成功。 |

通用交互修复优先进入 Terry React UI Library；业务 CSS 不越权修共享控件。上述条目与 UI_DEVELOPMENT_RULES 一起执行。

## 输入槽位增量（2026-09-20）

- 生成参数上方的提示行替换为工作流媒体输入槽位。Bridge 提供槽位类型与最终接入端口名；空槽位可见、可选，不要求全部填满。
- 先在槽位选择资产，之后才允许从 `@` 菜单引用；选择器按槽位类型过滤项目资产，可替换或清空。
- 槽位是输入来源，提示词中的标签只是引用。删除文本标签不再自动移除槽位资产。
- `generation.workflowInputs` 保存工作流 ID、端口身份、资产 ID 和引用标签。保留空槽位，不能把第三槽位的资产压到第一槽位。
- H3 的模型编号与物理端口后缀不是同一概念。官方 `MiniMaxH3ReferenceToVideo.execute` 跳过空输入，`comfy/text_encoders/minimax.py` 按有效引用连续编号；视频音轨与同后缀视频配对，音轨先占用 Audio 编号，再排列独立音频。
- Bridge 的 H3 专用适配在执行副本中按实际非空输入重写 Picture / Video / Audio 标签；不修改任务原文，不改其他模型规则。逻辑 Subject 标签不参与转换。引用空槽位时拒绝提交，不能误用压缩后碰巧相同的编号。
- 官方源码参考：[H3 节点](https://github.com/Comfy-Org/ComfyUI/blob/master/comfy_extras/nodes_minimax_h3.py)。本地核对文件：`G:/AIGC/ComfyUI_Codex/ComfyUI/comfy_extras/nodes_minimax_h3.py`、`comfy_api/latest/_io.py`、`comfy/text_encoders/minimax.py`。
