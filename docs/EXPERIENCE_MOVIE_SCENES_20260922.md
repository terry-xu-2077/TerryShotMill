## 已遇到的问题

### 1. 浏览器控制连接不可用，无法完成纯界面用户体验

尝试连接当前应用和重置后读取窗口清单，均返回 `nodeRepl.fetch request failed`，浏览器列表为空。应用本身的 HTTP 接口可访问。

处理：通过应用公开的项目、资产、任务和批量运行接口执行同一业务流程，不直接写数据库。必须区分：此轮能验证业务流程与运行结果，不能把接口操作声称为已完成真实鼠标逐步交互验收。属于自动化连接限制，尚不能归因于 ShotMill UI。

### 2. 预设显示720P不能证明工作流实际接收该参数

“均衡档”的名称及档位分辨率为720p，但原工作流仍接旧ResolutionSelector和PrimitiveFloat；新增Bridge分辨率、时长节点已安装却未接入这个工作流。需要逐个检查真实连线才能确认参数会被消费，普通用户很难从项目参数栏辨别。

处理：经用户批准建立独立工作流副本，接入Bridge分辨率、秒数选择器，分别直连H3宽高、length和CreateVideo帧率。原档位和默认档位不变。

建议后续：在档位配置中显示“分辨率／时长是否由项目控制”，并在提交前提示未绑定的选项。本次只记录，不改代码。

### 3. 显示时长与模型实际时长存在量化差异

H3以17n+5帧约束时长，24fps下设置8秒对应192帧，10秒对应243帧，12秒对应294帧。生成后仍需核查容器实际时长，不能仅看编辑框断言。
